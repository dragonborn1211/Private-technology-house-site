# Private Technology House — сайт (тёмная версия)

Одностраничный сайт студии, который **собирается из частиц**: первый экран при загрузке и каждый следующий блок,
когда он доезжает до экрана. Частицы обводят блоки, ложатся полосками строк, складываются в буквы, и только потом
проявляется настоящий текст. Палитра «Ледник»: тёмная, холодная.

Без фреймворков и сборки: HTML, CSS и JavaScript. Светлая версия сайта — в ветке [`light`](../../tree/light).

## Запуск

```bash
node tools/serve.mjs
```

Открыть http://localhost:8080. Сервер отдаёт только то, что идёт на хостинг: `index.html` и `assets/`.

## Структура

```
index.html            разметка всех секций
assets/site.css       стили
assets/engine.js      движок частиц (WebGL, 2D-фолбэк) и порядок сборки секций
assets/scenes.js      анимированные сцены в карточках «Объектов»
assets/scroll.js      мягкая прокрутка и свой скроллбар
assets/previews/      снимки сайтов для превью (обновляет node tools/previews.mjs)
tools/check.mjs       прогон в Chromium: стадии сборки, ошибки консоли, сцены, скриншоты на 3 ширинах
CLAUDE.md             как устроен сайт и о чём договорились — читать перед правками
BACKLOG.md            задачи и известные недочёты
```

## Проверка

```bash
npm install
npx playwright install chromium
node tools/check.mjs
```

Скриншоты появятся в `tools/shots/`. Проверка учитывает `prefers-reduced-motion`, перезагрузку в середине страницы
и адаптивное качество на слабых устройствах — подробности в `CLAUDE.md`.

## Хостинг

На хостинг нужны только `index.html` и `assets/`. Сайт статический, подойдёт любой статический хостинг
(GitHub Pages, Cloudflare Pages, Netlify).
